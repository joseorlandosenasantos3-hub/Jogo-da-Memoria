# Jogo da Memória

Jogo da memória feito com **HTML, CSS e JavaScript**. Encontre os pares de emojis antes que o tempo acabe e tente bater seu recorde.

## Como jogar

1. Abra o arquivo `index.html` em um navegador.
2. Clique em duas cartas para revelar os emojis.
3. Encontre todos os pares antes do cronômetro chegar a zero.
4. Use o botão **Reiniciar** para começar uma nova partida.

## Recursos

- Cartas embaralhadas a cada rodada.
- Contador de tentativas e pontuação.
- Modo Rush com cronômetro.
- Recorde salvo no navegador.
- Rodadas reiniciadas automaticamente após encontrar todos os pares.

## Tecnologias

- HTML
- CSS
- JavaScript
